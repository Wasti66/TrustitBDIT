# 🚀 IT Services Landing Page

A modern, responsive and interactive IT company landing page built using **HTML5, CSS3, JavaScript, and Tailwind CSS**.  
This project focuses on clean UI, smooth animations, and real-world frontend development practices.

---
## 🌐 Live Preview
https://wasti66.github.io/TrustitBDIT/

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Tailwind CSS  
- JavaScript (Vanilla JS)  
- Swiper JS (for slider)  
- Axios (for API integration)

---

## ✨ Features

### 🎯 Responsive Design
- Fully responsive layout for all devices (mobile, tablet, desktop)

### 🧭 Responsive Header
- Sticky/affix navigation bar  
- Mobile-friendly hamburger menu  

### 🎠 Banner Slider
- Implemented using **Swiper JS**
- Smooth sliding animation

### ⚡ Animated Sections
- Services section with hover animations  
- About section with clean UI transitions  

### 📬 Contact Section
- JavaScript form validation  
- User-friendly error handling
  ### 📰 Dynamic Post Section
- API integration using Axios  
- Data fetched from external API  
- **Load More button functionality**

### 🔼 Scroll To Top Button
- Smooth scroll animation  
- Appears on scroll for better UX  

### 📦 Footer Section
- Clean and structured footer design  

---

## 🔌 API Integration

- Used **JSONPlaceholder API** for dummy post data  
- Implemented dynamic rendering with JavaScript  
- Load more posts on button click

---

## 🎨 Why Tailwind CSS?

- Fast development process  
- Utility-first approach  
- Clean and maintainable code  
- Responsive design without writing heavy custom CSS  
- Easy customization and scalability
